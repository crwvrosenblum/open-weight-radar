How to read this watchlist

A curated comparison, independent of trending rank and repository age. Model names link to official public specifications. Parameter counts are the lab’s stated total and active counts; “class” is approximate. Unknown specifications stay unreviewed. Total size, active compute, precision, context length, and runtime all affect serving requirements; size alone is not a hardware estimate.

Weight files and CoreWeave’s public catalog are rechecked each build. “No weights observed” means no matching weight-bearing repository in the focused official-author search; it does not prove weights are unavailable elsewhere. Product/API availability is separate from weight availability. “No public match” does not establish that CoreWeave cannot serve a model. Listed model capabilities do not establish which modalities a provider enables.

Coverage and methodology

The snapshot combines the first 60 trending results per task (text, vision-language, image generation, video generation, speech generation, speech recognition, and robotics) with each tracked lab’s 60 most recently created repositories and focused official-author searches for the model watchlist. It includes supported generation, perception, and robotics tasks with public metadata and at least one weight file; adapter-only repositories are excluded. Quantized variants and fine-tunes may appear as distinct repositories. A task tag is a discovery signal, not proof of every supported input/output modality. This is a bounded sample, not a complete catalog of open models. Downloads are rolling 30-day counts; likes are cumulative; trending score is Hugging Face’s own momentum signal. Rank changes compare positions in the sampled trending list at consecutive successful builds; “New” means newly observed in that list. Rank movement starts after the first snapshot.
